## 需要第二阶段关注的缺陷记录

> 以下仅记录现象，7月25日前不修改业务规则

| 编号 | 模块 | 现象 | 建议 |
| --- | --- | --- | --- |
| WH-BUG-01 | 入库单服务 | `Ware_WareHouseBillService.Add()` 缺少明细校验，允许创建空明细的入库单 | 添加 `if (details == null \|\| details.Count == 0)` 校验 |
| WH-BUG-02 | 入库单服务 | `Ware_WareHouseBillService.Add()` 缺少数量校验，允许入库数量为零或负数 | 添加 `if (InStoreQty <= 0)` 校验 |
| WH-BUG-03 | 入库单服务 | 入库后库存更新逻辑被注释掉（`AddOnExecuted`），入库单创建后产品库存不会增加 | 取消注释或重新实现库存更新逻辑 |
| WH-BUG-04 | 编号生成 | `GetWareHouseBillCode()` 和 `GetOutWareHouseBillCode()` 代码重复，仅查询条件不同 | 抽取公共方法，减少重复代码 |
| WH-BUG-05 | 数据库 Schema | 建表 SQL 中 `InStoreQty`/`OutStoreQty` 定义为 `[int]`，但 C# 实体模型为 `decimal`。EF Core 查询时抛出 `Unable to cast object of type 'System.Int32' to type 'System.Decimal'`。打开出入库单明细页面时触发 | 执行 `ALTER TABLE dbo.Ware_WareHouseBillList ALTER COLUMN InStoreQty decimal(18,4) NOT NULL; ALTER TABLE dbo.Ware_OutWareHouseBillList ALTER COLUMN OutStoreQty decimal(18,4) NOT NULL;` （参考 `20260720-wf07-bom.sql`） |
