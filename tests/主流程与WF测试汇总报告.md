## 页面验收与修复记录（非测试实例）

本节来自人工页面观察；每个现象均进一步通过实际接口、数据库视图或存储过程调用确认根因和修复结果，因此不将其伪装为自动化测试实例。

### 首页数量统计中文显示为 `????`

人工观察：首页“数量统计”中的“装配工单”“生产计划”“销售订单”等中文标签显示为 `????`。

定位结果：`Home.vue` 仅直接显示接口字段 `item.ItemName`；`GET /api/Production_WorkOrder/getHomeStatisticsNumber` 所查询的 `dbo.HomeView_StatisticsNumber` 已直接返回 `????`，问题位于 SQL Server 字符串编码，而非 Vue 渲染。

修复：将视图中中文字符串字面量改为 Unicode 字面量，例如 `N'销售订单'`、`N'生产计划'`、`N'装配工单'`；同时更新新库导入脚本和已部署库升级脚本 [fix-home-statistics-unicode.sql](../数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/fix-home-statistics-unicode.sql)。

验证：修复后的视图已返回“装配工单 / 生产计划 / 销售订单 / 不良品总数 / 良品率 / 销售订单占比”等正常中文。首页运行时调用接口，刷新页面即可生效，无需修改 Vue 组件或重新构建前端。

### 生产工单列表显示“暂无数据”

人工观察：数据库 `Production_WorkOrder` 表有 35 条工单，但前端“生产工单”列表显示“暂无数据”。

定位结果：列表服务在返回每条工单前调用 `dbo.SerializeJSON` 写入工艺路线和进度；过程将包含“破洞”“焊接”等中文的 XML 转为 `VARCHAR(MAX)`，触发 `Conversion of one or more characters from XML to target collation impossible`，接口无法返回分页数据。

修复：将 `dbo.SerializeJSON` 的参数、动态 SQL、XML/JSON 字符串和中文拼接字面量统一改为 `NVARCHAR` 或 Unicode 字面量。修改同步写入新库初始化脚本 [iMES20221014.docker.sql](../数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/iMES20221014.docker.sql) 和已部署库升级脚本。

验证：以真实工单 `GD202208062336180001` 查询工艺进度，已成功返回“破洞”“焊接”及 `100.00%` 进度；数据库过程错误消除，刷新“生产工单”页面即可重新取得列表，无需修改 Vue 组件。
