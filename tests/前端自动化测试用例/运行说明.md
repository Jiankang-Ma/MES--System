# Vue 前端自动化测试用例

本目录用于测试以下文件，不修改 `src` 业务源码：

- `src/uitils/common.js`
- `src/uitils/dateFormatUtil.js`
- `src/components/basic/ViewGrid/ViewGridCustomColumn.js`

## 执行

先在 `源码/iMES.Vue3` 安装与 `package-lock.json` 对应的依赖，然后从仓库根目录执行：

```powershell
& '.\tests\前端自动化测试用例\run-tests.ps1'
```

脚本会切换到 Vue 项目目录，并显式加载本目录中的 `*.spec.js`。测试文件因此可以保留在仓库根目录的 `tests` 下，无需修改 Vue 项目的 `package.json` 或业务源码。
