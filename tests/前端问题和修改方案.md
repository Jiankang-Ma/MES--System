# 前端问题和修改方案

## 问题

首页“数量统计”中的“装配工单”“生产计划”“销售订单”等中文标签显示为 `????`。

前端组件 `源码/iMES.Vue3/src/views/Home.vue` 只是调用接口并显示 `item.ItemName`，没有做字符转换：

```vue
<div class="demo-color-name">{{ item.ItemName }}</div>
```

接口 `GET /api/Production_WorkOrder/getHomeStatisticsNumber` 查询 SQL Server 视图 `dbo.HomeView_StatisticsNumber`。实际查询该视图时，数据库返回的是 `????`，因此问题发生在数据库层，而不是 Vue 页面或浏览器编码。

## 原因

视图内原先使用普通字符串字面量：

```sql
WHEN 'SalesOrder' THEN '销售订单'
```

在当前 Linux SQL Server 的非中文代码页环境中，普通字符串会先按数据库代码页转换，无法表达的中文会变成问号。

## 核心修改

将所有需要返回中文的 SQL Server 字符串字面量改为 Unicode 字面量：

```sql
WHEN 'SalesOrder' THEN N'销售订单'
WHEN 'ProductPlan' THEN N'生产计划'
WHEN 'AssembleWorkOrder' THEN N'装配工单'
```

同样处理了“不良品总数”“良品率”“销售订单占比”。`N` 前缀使 SQL Server 将该字符串作为 Unicode 保存和返回，不再受数据库代码页影响。

## 为什么有两个 SQL 文件修改

`数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/iMES20221014.docker.sql` 是新建 Docker 数据库时的导入脚本。修改它可以保证以后重新初始化数据库时不会再产生该问题。

但当前运行中的 `iMES` 数据库已经在修改前创建完成。修改导入脚本不会回写当前数据库中已有的视图定义，因此新增：

`数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/fix-home-statistics-unicode.sql`

该文件执行 `ALTER VIEW dbo.HomeView_StatisticsNumber` 和 `ALTER PROCEDURE dbo.SerializeJSON`，不修改任何业务表或业务数据。它用于把 Unicode 修复应用到已部署数据库，也可以重复执行。

## 已验证结果

修复后，当前数据库视图已返回：

```text
装配工单  AssembleWorkOrder
生产计划  ProductPlan
销售订单  SalesOrder
不良品总数 DefectItem
良品率    YieldRate
销售订单占比 SalesRate
```

前端是运行时调用该接口，因此不需要修改 Vue 代码或重新构建前端；刷新首页即可生效。

## 生产工单列表显示“暂无数据”（2026-07-15）

### 表现

`Production_WorkOrder` 表实际有 35 条工单，但前端“生产工单”列表显示“暂无数据”。这不是分页条件或 Vue 渲染问题。

### 原因

列表查询完成后，[Production_WorkOrderService.cs](/Users/yuanzhuoshen/Desktop/MES系统源码Docker部署/源码/iMES.Net/iMES.Production/Services/Production/Partial/Production_WorkOrderService.cs:64) 会针对每条工单调用 `dbo.SerializeJSON`，把工艺路线和进度写入 `ProductionSchedule` 后再返回页面。

原过程使用 `VARCHAR` 保存动态 SQL、XML 文本及 JSON 文本，并执行：

```sql
SET @XMLString = CAST(@XML AS VARCHAR(MAX))
```

工艺名称包含“破洞”“焊接”等中文字符。在 Linux SQL Server 的当前排序规则/代码页下，该转换报错：

```text
Conversion of one or more characters from XML to target collation impossible
```

因此接口在处理列表记录时失败，前端无法取得分页数据，最终显示“暂无数据”。

### 修改

将 `dbo.SerializeJSON` 的输入参数、动态 SQL、XML 字符串、JSON 字符串和拼接字面量统一改为 Unicode 类型或 Unicode 字面量：

```sql
@ParameterSQL AS NVARCHAR(MAX)
SET @XMLString = CAST(@XML AS NVARCHAR(MAX))
```

修改位置：

- 新数据库初始化脚本：[iMES20221014.docker.sql](/Users/yuanzhuoshen/Desktop/MES系统源码Docker部署/数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/iMES20221014.docker.sql:31439)
- 已部署数据库升级脚本：[fix-home-statistics-unicode.sql](/Users/yuanzhuoshen/Desktop/MES系统源码Docker部署/数据库/DB/iMES-SQLServer2016/iMES20221014/docker-import/fix-home-statistics-unicode.sql:51)

没有修改 Vue 组件，也没有新增 SQL 文件。原有的 `fix-home-statistics-unicode.sql` 已包含首页视图与该存储过程的 `ALTER` 语句，用于已经部署的数据库；初始化脚本保证新环境首次导入也使用修复后的定义。

```json

  {"Sequence":"1","ProcessName":"破洞","PercentNum":"100.00%"},
  {"Sequence":"2","ProcessName":"焊接","PercentNum":"100.00%"}

```

数据库过程错误已消除。刷新“生产工单”页面即可重新获取列表；无需重新构建前端。
