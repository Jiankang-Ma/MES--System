## 已修复：装配工单明细生产进度 SQL 拼接（2026-07-22）

### 影响接口

`POST /api/Production_AssembleWorkOrder/GetDetailPage`

代码位置：`源码/iMES.Net/iMES.Production/Services/Production/Partial/Production_AssembleWorkOrderService.cs:398-404`。

### 修改内容

修复前将 `WorkOrderCode` 和 `ProcessLine_Id` 拼接成可执行 SQL 字符串，并传入 `SerializeJSON` 存储过程。

修复后改为 Dapper 参数绑定查询，并继续把结果序列化为字符串，避免影响前端 `JSON.parse(scope.row.ProductionSchedule)`：

```csharp
const string progressSql = @"select * from Func_GetProcessLineAndProgressByID(@workOrderCode, @processLineId)";
object obj = DBServerProvider.SqlDapper.QueryDynamicList(progressSql, new
{
    workOrderCode = detailGrid.rows[i].WorkOrderCode,
    processLineId = detailGrid.rows[i].ProcessLine_Id
});
detailGrid.rows[i].ProductionSchedule = obj.Serialize();
```

`workOrderCode` 与 `processLineId` 会作为 SQL 参数传递，而不是 SQL 语法的一部分；返回字段与前端消费格式保持不变。

## 已修复：打印模板保存接口匿名写入（2026-07-22）

### 影响接口

`GET/POST /api/Base_PrintTemplate/saveOrUpdateData`

代码位置：`源码/iMES.Net/iMES.WebApi/Controllers/Custom/Partial/Base_PrintTemplateController.cs:70-72`。

### 修改内容

修复前：

```csharp
[HttpPost, HttpGet, Route("saveOrUpdateData"), AllowAnonymous]
```
