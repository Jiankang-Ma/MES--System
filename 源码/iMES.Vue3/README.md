# mes.vue3

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Run your unit tests
```
npm run test:unit
```

All Vue unit tests are maintained in `tests/unit/`. The command works on macOS,
Windows, and Linux; it automatically enables the compatibility setting required by
the current Vue CLI 4/Webpack toolchain when Node.js 17 or later is used.
